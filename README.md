# MindPal

Calm wellness companion. This repository is the **MindPal** phone-hosted shell (GitHub Pages).

## In-app modules
- **Verse for the Day** — `content/verse-of-the-day.json` (modular feed; Denyse / live-face may consume the same contract)
- **Daily readings** — `content/daily-readings.json` (210 originals, v2.0.0)
- **Book (interactive reader)** — private user PDFs only; text reflow + chapter rail; device Listen via Web Speech (offline); pdf.js CDN; position in localStorage; optional PDF bytes / future chapter audio in IndexedDB

## Not a spin-off
Add to Home Screen installs **MindPal**. Do not brand this as a separate PWA product.
